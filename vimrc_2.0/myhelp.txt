*myhelp.txt* *myhelp*   我的 Vim 速查笔记

本帮助文档收录了 Vim 的常用快捷键、命令以及示例，供快速参考。

==============================================================================
基本 *basic*
    d 删除 delete
    r 替换 replace
    c 修改 change
    y 复制 yank
    v 选取 visual select
    p 粘贴 paste
    
    w 单词word
    s sentence
    p 段落paragraph
    t HTML标签tag
    
    i “在…之内”inside
    a “环绕…”around
    t “到…位置前”to
    f “到…位置上”forward

    0 移动到行首第一个字符位置（绝对行首，列号 0）
    ^ 移动到行首非空白字符位置（文字位置）
    $ 移动到行尾

    gg 移动到文件第一行
    G  移动到文件最后一行

    % 跳到对应括号处（普通模式下）
        d%   删除括号与它配对括号之间的内容
        y%   复制括号内的内容

      当前文件名（命令行模式下）
        :!ls %             执行 shell 命令 ls 当前文件名。
        :!gcc % -o myprog  :!gcc % -o myprog

    ! 用来执行外部 shell 命令或对文本进行过滤
        :%!sort   用外部 sort 命令处理，并替换原文本


    di( 或 di)  删除()内的内容
    ci( 或 ci)  修改()内的内容
    vi( 或 vi)  选取()内的内容
    di"  ci"  vi" 操作双引号内的内容
    ciw 修改一个单词
    caw 修改一个单词
    df; 删除到分号
    dt; 删除到分号（不包含分号）
    d$  删除到行尾
    D   删除光标处至末尾
    dip 删除一个段落
    vis 选取一个段落
    cis 修改一个段落

复制黏贴  *copy* *paste*
    yy - 复制当前行
    dd - 剪切当前行
    p  - 粘贴内容
    ddp - 交换当前行与下一行
    Ctrl+r+{register} - 插入寄存器内容(在插入模式下)
        Ctrl+r a - 插入寄存器 a 的内容
        Ctrl+r + - 插入寄存器 + 的内容, 从系统剪贴板粘贴
    ggyG - 全选并复制

==============================================================================
寄存器  *register*
    "ay 复制到寄存器("a)
    "ap 从寄存器粘贴("a)
    Ctrl+r a  插入寄存器 a 的内容(在插入模式下)
    Ctrl+r +  插入寄存器 + 的内容, 从系统剪贴板粘贴(插入模式下)

    无名寄存器("")
        每次执行剪切（d、c、x）或复制（y）时自动更新。
        当你粘贴时（p 或 P），默认使用的就是无名寄存器。

    命名寄存器("a "b "c ... "z)
        通过 "a 到 "z 的命名寄存器可以保存内容，便于重复使用。
        小写寄存器 ("a 到 "z)：会将新的内容覆盖保存到指定的寄存器。
        大写寄存器 ("A 到 "Z)：会将新的内容追加到寄存器中（不会覆盖前面的内容）。

    数字寄存器("0 "1 "2 ... "9)
        0 寄存器：自动保存最新复制的内容（y 操作）。
        1 到 9 寄存器：用于保存最近的删除内容（历史记录）。
        "1 保存的是最近一次的删除内容，"2 保存的是倒数第二次的删除内容，以此类推。

    系统剪贴板寄存器
        "+y 复制到系统剪贴板("+ 寄存器：访问系统剪贴板（通常通过 Ctrl+C/Ctrl+V 操作）) 
        "*y 复制到系统剪贴板("* 寄存器：访问系统的选区，比如鼠标中键粘贴的区域)
        "+p 从系统剪贴板粘贴(系统剪贴板)
        "*p 从系统剪贴板粘贴(系统的选区，比如鼠标中键粘贴的区域)

    小删除寄存器("-)
        用于存储“较短的删除内容”（小范围删除，如 x 或 d 操作的字符或部分行）。
        若使用 dd 等较大范围的删除操作，小删除寄存器不会记录。

查找替换 *search* *replace*
    例子：
    :s/foo/bar/g        当前行全替换，把foo替换为bar
    :%s/foo/bar/g       全文全替换
    :%s/foo/bar/gI       全文全替换，并且大小写敏感
    :n1,n2s/foo/bar/g   指定行号范围替换
    :'<,'>s/foo/bar/g   可视模式选区替换

    :[range]s/{pattern}/{string}/[flags]
        - range：作用的行范围（可以省略）。
            %	    全文（文件的所有行）
            n1,n2	从第 n1 行到第 n2 行
            '<,'>	可视模式选区范围（Visual mode 选区后输入 : 会自动补全）
            (省略)    当前行
        - pattern：要查找的正则或文本。
            默认（无标志） →    每行仅替换第一个匹配
            g   → global，      每行替换所有匹配
            c   → confirm，     每次匹配时确认（yes/no/quit/all）
            i   → ignorecase，  忽略大小写
            I   → noignorecase，大小写敏感（覆盖 ignorecase 选项）
            可以组合使用，例如：
            gc  → 全局替换 + 确认
            gi  → 全局替换 + 忽略大小写
            gIc → 全局 + 大小写敏感 + 确认
        - string：替换成的文本。
        - flags：替换行为标志（后面介绍）。
    :&  可以用 & 重复上一次替换。

比对 *diff*
    :diffthis  - 将当前窗口标记为 diff 模式
        切到第一个窗口：   :diffthis
        切到第二个窗口：   :diffthis
    :diffoff   - 关闭 diff 模式
    :diffoff!  - 全部退出 diff
    :diffsplit - 在新窗口中打开 diff 模式
    :diffget（简写 do） - （从“对方”获取）将另一边的改动合并到当前
    :diffput（简写 dp） - （发送到“对方”）将当前窗口的内容放入 diff 窗口
    :diffupdate - 重新计算 diff

折叠 *folding*
    zc  - 折叠当前行
    zo  - 展开当前行
    zC  - 折叠所有子项
    zO  - 展开所有子项
    za  - 切换当前行的折叠状态（开/关）
    zA  - 切换所有子项的折叠状态（开/关）
    zx  - 删除当前行的折叠
    zX  - 删除所有子项的折叠
    zm  - 折叠更多
    zM  - 折叠所有
    zr  - 展开更多
    zR  - 展开所有

    :set syntax=markdown   设置当前文件的语法高亮为 Markdown
    :set syntax=vim        设置当前文件的语法高亮为 Vim script

终端 *terminal*
    :terminal    打开一个terminal窗口
    :hide        隐藏这个窗口
    :sb 2        横向分屏打开 buffer 2
    :vert sb 2   竖向分屏打开 buffer 2


    滚动模式（Terminal-Normal） - （先按 Ctrl-\，再按 Ctrl-n）
        滚动/查看 log
            j/k、Ctrl-f/Ctrl-b、PgUp/PgDn
            gg 到最上面，G 到最下面
            /关键字 搜索，n/N 跳转
    回到终端输入 - 按 i 或 a 返回输入。或者直接点一下/进入插入也会回去（取决于设置）

    qa   - 录制宏 a（[a-z]）
    q    - 停止录制宏
    @a   - 使用宏 a，例如 3@a 重复执行 3 次
    @@   - 重新执行上次执行的宏

十六进制编辑器模式 *hex-edit*
    :%!xxd      转换成十六进制转储的文本格式（%当前文件，!用来执行外部 shell 命令或对文本进行过滤）
    :%!xxd -r   恢复成二进制文件(-r是 xxd 的选项，表示 reverse（反转），即从十六进制转储文本恢复回原始二进制数据。)
    :w          保存当前文件

大小写转换 *uppercase* *lowercase* *ChangeCase*

    ~  - 将选中本文大小写切换，VISUAL模式
    u  - 将选中文本转换为小写，VISUAL模式
    U  - 将选中文本转换为大写，VISUAL模式
    gu - 转小写
    gU - 转大写
    gUU 将当前行的字母改成大写
    guu 将当前行的字母全改成小写

保存与退出 *writing* *quitting*
    :wq                    保存并退出
    :x                     保存并退出
    :w !sudo tee %         使用 sudo 保存当前文件

拖屏 *scrolling-motions*

    H  - 移动光标到当前屏幕的顶部（Top of screen）
    M  - 移动光标到当前屏幕的中间（Middle of screen）
    L  - 移动光标到当前屏幕的底部（Bottom of screen）

    zt - 滚动屏幕使光标位于屏幕顶部（Scroll line to Top）
    zz - 滚动屏幕使光标居中显示（Scroll line to Center）
    zb - 滚动屏幕使光标位于屏幕底部（Scroll line to Bottom）

    G  - 跳转到文件最后一行（Go to last line）
    gg - 跳转到文件第一行（Go to first line）

dos转unix文件格式 *dos2unix*
    find ~/.vim/pack/vendor/opt/vim-auto-popmenu/ \
        -type f \( -name "*.vim" -o -name "*.txt" -o -name "*.md" -o -name "*.lua" \) \
        -exec dos2unix {} \;

==============================================================================
浏览器 *explorer-commands*

    :20Lexplore               左侧文件浏览器开关（显示/隐藏）
    :[N]Explore[!]  [dir]...  浏览当前文件所在目录
    :[N]Hexplore[!] [dir]...  水平分割窗口并打开文件浏览器
    :[N]Lexplore[!] [dir]...  左侧文件浏览器开关（显示/隐藏）
    :[N]Sexplore[!] [dir]...  分割窗口并浏览当前文件的目录
    :[N]Vexplore[!] [dir]...  垂直分割窗口并打开文件浏览器
    :Texplore       [dir]...  在新标签页中打开文件浏览器
    :Rexplore             ... 返回或切换到文件浏览器窗口

说明：
- `[N]`：可选数字，指定窗口高度或宽度（如 `20Vexplore` 表示开一个宽 20 列的窗口）。
- `[!]`：加感叹号表示强制刷新目录缓存。
- 不带路径时，默认操作当前文件所在的目录。
- 推荐使用 `:Lexplore` 快速开启左侧文件树视图。

示例：
    :Explore ~/projects     " 打开指定目录
    :Vexplore               " 垂直分屏浏览当前目录
    :Lexplore               " 左侧打开/关闭文件浏览器（toggle）
    :Rexplore               " 在编辑区与浏览器之间切换

==============================================================================
位置标记 *marks*
    [反引号(`)或单引号(')跳转至标记位置]
    单引号跳转至该标记所在行的非空行首

    :marks            - 标记列表
    ma                - 设置当前位置为标记 a
    `a                - 跳转到标记 a 的位置
    y'a               - 复制当前位置到标记 a 的内容
    `.                - 跳转到上次修改的位置
    ``                - 跳转回上次跳转前的位置
    :delm {marks}     - 删除指定的位置标记
    :delm!            - 删除当前缓冲区所有的位置标记，不包括 A-Z 或 0-9 的持久标记

    zf   - 创建折叠（选中多行再按 zf，同 :fo）
    zd   - 删除折叠
    za   - 展开/关闭切换
    zR   - 全部展开
    zE   - 删除所有折叠
    zo   - 展开

    zj   - 移动到下一折叠处

==============================================================================
运算（插入模式中） *expression-register*
    按 <C-r>= 可进行表达式运算。

    基本运算:
        加法 (+), 减法 (-), 乘法 (*), 除法 (/), 取模 (%)
    括号:
        ()
    内置函数:
        sin(), cos(), sqrt(), abs() 等
    变量:
        可使用和设置 VimScript 的变量 (:let a = 10 :echo a * 2)
    字符串操作:
        字符串连接、截取等
    类型转换:
        str2nr("123")
    十六进制数:
        printf("0x%X", 0x1234545 + 0x76543212)
    十进制数:
        0x12+0x34
